نظام ERP متكامل واحترافي موجه خصيصاً لـ **مصانع ومشاغل وتوكيلات الملابس الجاهزة (Clothing Factory & Retail)**. صُمم النظام بالكامل بواجهة عربية تفاعلية حديثة من اليمين إلى اليسار (RTL)، ليدير دورة تصنيع وتجارة الملابس المتكاملة: من توريد الأقمشة والإكسسوارات، تتبع مراحل التشغيل (قص $\leftarrow$ خياطة $\leftarrow$ كوي وتعبئة)، هالك القماش، والتصنيع لدى الغير (تطريز، طباعة، غسيل جينز)، وصولاً إلى معارض ومنافذ التوزيع، فواتير المبيعات، مرتجعات الكاشير، تقفيل الورديات اليومية، وخزينة مجمعة مركزية.

## 🌟 المزايا المعمارية والتقنية (Architecture & Highlights)

1. **معمارية خالية من الخوادم (Zero Backend / Serverless)**:
   - يعمل النظام كلياً داخل متصفح المستخدم عبر تقنية `IndexedDB` ومكتبة `Dexie.js` بمخطط بيانات محدث الإصدار الرابع (`ApexEnterpriseERP_DB_v4`).
   - لا حاجة لاستئجار خوادم سحابية أو قواعد بيانات شهرية مدفوعة (Zero Infrastructure Cost).

2. **تشغيل أوفلاين فوري (100% Offline-First)**:
   - استجابة فائقة السرعة بزمن استجابة فوري (0ms Latency) لجميع العمليات والحركات المحاسبية والمخزنية دون الحاجة لشبكة الإنترنت.

3. **ضغط وتخزين الصور محلياً (HTML5 Canvas Compression)**:
   - ضغط صور موديلات الملابس تلقائياً وتحويلها إلى Base64 خفيفة الحجم لضمان سرعة فائقة في التصفح وسعة تخزين اقتصادية.

4. **تحقق فوري شامل باللغة العربية (Form Validation Engine)**:
   - فحص متزامن للحقول الإجبارية، الأرقام الموجبة، تفرد الأكواد التسلسلية، وإظهار رسائل خطأ عربية تحت كل حقل مع تعطيل أزرار الحفظ حتى استيفاء البيانات السليمة.

5. **محرك احتساب تكاليف هندسي ومحاسبي نقي (Pure TypeScript Engine)**:
   - حساب فوري لمتوسط التكلفة المرجح، شجرة المنتجات (BOM) مع نسبة هالك القماش، أجور مراحل القص والخياطة، تراكم تكلفة التشغيل الخارجي، وتكلفة البضاعة المباعة (COGS) بدقة تامة ومختبر بـ Vitest (26 اختباراً أخضر بنسبة 100%).

6. **طباعة مزدوجة متقدمة وتصدير Excel (A4 & 80mm Thermal Receipt)**:
   - دعم التبديل بين نموذج الفاتورة الضريبية قياس **A4** ونموذج **الإيصال الحراري للكاشير 80mm**، مع إمكانية تصدير كافة الجداول والتقارير إلى ملفات Microsoft Excel حقيقية (`.xlsx`).

## 📦 الوحدات الوظيفية للنظام (Clothing Factory Modules)

### 1. البيانات الأساسية الموحدة (Master Data & Clothing Items)
- **شاشة الأصناف الموحدة (`Items`)**:
  - تصنيف الموديلات والأقمشة (المجموعة، القسم، الاسم، النوع: تام الصنع / خامات ومستلزمات).
  - رفع صور الموديلات مضغوطة بتقنية Canvas Base64.
  - اعتماد مسمى **"سعر التكلفة"** في كافة أنحاء النظام بدلاً من "السعر التقديري".
  - **كود الصنف التسلسلي التلقائي**: ترقيم تسلسلي تصاعدي يستكمل من أعلى كود مسجل، مع إمكانية التعديل والتحقق من التفرد.
  - **متغيرات الملابس (Size & Color Variants)**: إدارة المقاسات والألوان كبيانات أساسية، مع رصيد جرد مستقل لكل توليفة (مقاس/لون).
- **شاشة الأطراف الموحدة (Unified Parties)**:
  - دمج الموردين والعملاء في سجل واحد مع خياري تحديد (`مورد` / `عميل` / كلاهما معاً).
  - حصر حقل **"الحد الائتماني"** على العملاء فقط وإلغاء سقف الموردين.
  - احتساب صافي الرصيد للأطراف المشتركة وإجراء **المقاصة الحسابية (Offset)** بضغطة زر.
- **طرق دفع الموردين**: إدارة طرق السداد (نقدية، تحويل بنكي، شيكات) واختيارها عند الصرف.
- **مواقع التخزين والأرفف**: إدارة مخازن الخامات، عنابر الإنتاج، ومستودعات المنتجات التامة.
- **أكواد المصروفات**: دليل أكواد المصاريف مع الاسم والمبلغ الافتراضي وسرعة الإدراج.
- **أزرار الاختصار السريعة**: القفز المباشر لإضافة مورد أو عميل أو صنف من شاشات الحركات.

### 2. أوامر الشراء ومشتريات الأقمشة (Purchase Orders - PO)
- جلب سعر التكلفة من بطاقة الصنف تلقائياً عند الاختيار، وتحديث سعر التكلفة في قاعدة البيانات تلقائياً عند تعديل السعر بالطلب (اعتماد آخر سعر شراء للعرض والمتوسط المرجح للتكلفة).
- شروط السداد: **نقدي (Cash)** بدون تاريخ استحقاق، أو **آجل (Credit)** مع تحديد تاريخ الاستحقاق وعدد الأيام.
- إجماليات متقدمة: ربط متبادل وتلقائي بين نسبة الخصم (%) وقيمته بالجنيه، إضافة مصاريف الشحن والنقل والنولون، وحساب الإجمالي النهائي.

### 3. المخزون والمستودعات والتسويات (Inventory & Storage)
- **الرصيد الفعلي**: رصيد أول المدة (مدخل لمرة واحدة) + صافي الحركات التراكمية = الرصيد الفعلي الحالي.
- **تسويات الجرد المخزنية**:
  - عجز: هالك تصنيع، أو عينات وفحص جودة.
  - إضافة: فائض جردي.
  - **قاعدة محاسبية صارمة**: تسويات الجرد تغير الكميات فقط **دون أي أثر مالي أو محاسبي** مع سجل تدقيق معتمد (Audit Trail).
- **التحويل بين مواقع التخزين**: نقل الخامات والموديلات بين المخازن وعنابر التشغيل.

### 4. أوامر الإنتاج ومراحل التشغيل (Manufacturing Orders)
- **التحقق من الحد الأدنى للتشغيل**: إظهار تنبيه وتحذير فوري باللغة العربية عند إدخال كمية دفعة إنتاجية أقل من الحد الأدنى للتشغيل للموديل.
- **مراحل تصنيع الملابس**: تقسيم التشغيل الداخلي إلى مراحل:
  1. مرحلة القص (Cutting).
  2. مرحلة الخياطة والتجميع (Sewing).
  3. مرحلة الكوي والتعبئة والتغليف (Ironing & Packing).
- **هالك القماش**: احتساب نسبة هالك القص تلقائياً في شجرة المنتج (BOM) وتكلفة الدفعة.

### 5. التصنيع لدى الغير (Outsourced Manufacturing)
- استبدال مرحلة التشطيب التقليدية بشاشة متكاملة لـ **التصنيع لدى الغير**:
  - اختيار المصنع أو الورشة الخارجية (مورد من نوع "خدمة" للتطريز أو الطباعة أو غسيل الجينز Stone Wash).
  - معادلة التكلفة التراكمية الدقيقة:
    $$\text{تكلفة المرحلة الداخلية (أقمشة + قص وخياطة)} + \text{تكلفة التشغيل الخارجي (خدمة + نقل)} = \text{التكلفة النهائية التراكمية للمنتج}$$
  - استلام البضاعة الجاهزة وتحويلها مباشرة لمخزن التام ومعارض البيع.

### 6. المبيعات وفواتير منافذ التوزيع (Sales & Cashier POS)
- فواتير مبيعات نقدية وآجلة (النقدي بدون تاريخ استحقاق).
- تفصيل كل سطر: السعر قبل الخصم، قيمة الخصم، والسعر الصافي بعد الخصم، مع إجمالي الفاتورة.
- **فحص الحد الائتماني الفوري**: إظهار رصيد العميل الحالي فور اختياره؛ وحظر حفظ الفاتورة الآجلة برسالة عربية واضحة في حال تجاوز الرصيد الحد الائتماني المصرح به.
- **مرتجعات المبيعات**:
  - *مرتجع حر*: بدون فاتورة أصلية.
  - *مرتجع مرتبط بفاتورة مبيعات*: التحقق الصارم من عدم تجاوز الكمية المرتجعة للكمية المباعة، واستعادة كميات المخزون فورياً، مع خصم القيمة من حساب العميل (آجل) أو ردها نقداً من خزينة المنفذ (نقدي).
- **معاينة وطباعة الفاتورة**: دعم التبديل المباشر بين نموذج **A4 الكامل** ونموذج **إيصال الكاشير الحراري (80mm)**.

### 7. الخزينة وصرف النقدية ومنافذ البيع (Treasury & Cash Out)
- **صرف النقدية (بديل المصاريف الشهرية)**: اختيار كود المصروف، التحميل التلقائي للمبلغ الافتراضي مع إمكانية تعديله، واختيار الخزينة لإثبات سند الصرف فورياً.
- **هيكل الخزائن المتعدد**:
  - خزينة مستقلة لكل منفذ بيع ومعرض.
  - **خزينة رئيسية مجمعة مركزية** تستقبل وتراقب كافة التوريدات.
- **توريد المنفذ للخزينة الرئيسية**: شاشة تحويل نقدية المعارض إلى الخزينة المركزية.
- **تقفيل الوردية اليومي (Daily Shift Closings)**: شاشة تقفيل وردية الكاشير لكل منفذ بيع، مطابقة العهدة والمبيعات والمصروفات مع النقدية الفعلية وتوثيق العجز أو الزيادة.

### 8. تقارير المنتجات والتكاليف (Products Report & Analytics)
- **تقرير المنتجات والتكاليف التراكمي (Products Report)**:
  - استعراض: سعر التكلفة، متوسط سعر التكلفة، سعر البيع، متوسط سعر البيع، الرصيد الفعلي، إجمالي التكلفة، وإجمالي القيمة البيعية، وهوامش الأرباح.
  - أدوات بحث وفلترة بالمجموعات ونوع الصنف، والتصدير إلى Excel والطباعة.
- كشوف الأرباح، تفاصيل مراحل التصنيع، وتحليل أعمار الديون.

### 9. الصلاحيات وإدارة البيانات (RBAC & Backup)
- صلاحية مخصصة لـ **كاشير منفذ البيع** يرى مبيعات وخزينة المنفذ المخصص له فقط.
- نسخة احتياطية كاملة JSON، استيراد فوري، وتخزين دائم في المتصفح.

## 👥 مصفوفة الصلاحيات وأدوار النظام (RBAC Roles)

| الدور | المسمى الوظيفي | نطاق الصلاحيات |
|---|---|---|
| `owner` | **الرئيس التنفيذي (CEO)** | وصول كامل لكافة الشاشات، كشوف الأرباح، وإعدادات النظام المتقدمة |
| `accountant` | **المدير المالي (CFO)** | إدارة الفواتير، التحصيلات، سندات الخزينة، التوريدات، والتقارير المالية |
| `production` | **مدير الإنتاج والتشغيل** | شجرة منتجات الملابس (BOM)، أوامر الإنتاج، والتصنيع لدى الغير |
| `storekeeper` | **أمين مستودع الخامات** | أذونات الاستلام (GRN)، تسويات الجرد، التحويل بين المخازن، وكروت الأصناف |
| `purchasing` | **مدير سلاسل الإمداد ومشتريات الأقمشة** | سجل الموردين، أوامر شراء الخامات (PO)، ومتابعة أسعار التكلفة |
| `cashier` | **كاشير منفذ البيع والمعرض** | فواتير المبيعات، مرتجعات المنفذ، وصرف نقدية المنفذ التابع له فقط |

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend Core**: React 19, JavaScript / TypeScript, HTML5 Semantic RTL.
- **Styling**: Tailwind CSS v4, Lucide React Icons.
- **Data Layer**: Dexie.js (IndexedDB ORM Wrapper v4).
- **Canvas Compression**: HTML5 Canvas API للضغط المحلي الفوري للصور.
- **Exporting & Reporting**: SheetJS (`xlsx`) للتقارير المجدولة والطباعة (A4 & 80mm Thermal).
- **Security**: Web Crypto API (SHA-256 with Salt).
- **Tooling & Testing**: Vite 6, Vitest (26 Unit Tests covering Costing, Balances, & Auth).

## 🚀 التشغيل المحلي (Local Development)

```bash
# 1. استنساخ المستودع
git clone https://github.com/Mohamed-waled301/ERP-system.git
cd ERP-system

# 2. تثبيت الحزم

# 4. تشغيل اختبارات النظام ومحرك التكاليف (Vitest)

npm run build
```

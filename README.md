# نظام إدارة وتكاليف المصانع والورش (ERP المعلم) 🛠️🏭
### النسخة المستقلة بالكامل (100% Frontend Client-Only App)

نظام ERP مبسط واحترافي موجه لأصحاب الورش والمصانع والمعلمين في مصر والعالم العربي، مصمم بالكامل بواجهة عربية موحدة (RTL) لإدارة حركة المشتريات، الخامات، شجرة المنتجات (BOM)، التصنيع على مرحلتين (نجارة وتشطيب)، المبيعات، الخزينة، وتقارير التكاليف والأرباح.

---

## 🌟 مميزات المعمارية الجديدة (Frontend-Only Architecture)
1. **بدون خادم إطلاقاً (Zero Backend)**: تم الاستغناء بالكامل عن خوادم Node.js وExpress وقواعد بيانات PostgreSQL أو Supabase.
2. **تخزين محلي سريع وفوري (IndexedDB via Dexie)**: جميع الجداول والسجلات تُحفظ داخل متصفح جهاز المستخدم بدون أي استهلاك للإنترنت أو بطء في الاتصال.
3. **أمان تام وسرية مالية**: بيانات وأسعار وتكاليف الورشة لا تغادر جهازك إلى أي خادم خارجي.
4. **جاهز للنشر المجاني على Vercel بضغطة واحدة**: موقع ثابت (Static Site) يُبنى مباشرة عبر `Vite` ويُنشر على Vercel أو Netlify أو GitHub Pages.
5. **محرك احتساب تكاليف نقي (Pure TypeScript Engine)**: تم نقل جميع معادلات التكاليف (متوسط التكلفة المرجح، استهلاك شجرة المنتج مع نسبة الهالك، أجور العمالة، نصيب ساعة التشغيل من مصاريف المصنع، تكلفة مرحلة 1 ومرحلة 2، وصافي الأرباح) إلى دوال نقية مختبرة بوحدات فحص Vitest بنسبة نجاح 100%.

## 🚀 خطوات النشر على Vercel (Step-by-Step Vercel Deployment)

النظام مهيأ تلقائياً للعمل على Vercel بالإعدادات الافتراضية ودون الحاجة لأي متغيرات بيئة (Zero Environment Variables).

### الخطوة 1: رفع المشروع على GitHub
```bash
git init
git add .
git commit -m "Initial commit of 100% frontend Workshop ERP"
git remote add origin https://github.com/YOUR_USERNAME/workshop-erp.git
git branch -M main
git push -u origin main
```

### الخطوة 2: استيراد المشروع في Vercel
1. سجّل الدخول إلى موقع [Vercel](https://vercel.com).
2. اضغط على **"Add New..."** ثم اختر **"Project"**.
3. اختر مستودع الـ GitHub الخاص بالمشروع (`workshop-erp`).

### الخطوة 3: إعدادات البناء (Build Settings)
- **Framework Preset**: سيقرأه تلقائياً كـ **Vite**.
- **Root Directory**: اتركه الافتراضي (`./`).
- **Build Command**: الافتراضي `npm run build` (أو `vite build`).
- **Output Directory**: الافتراضي `dist`.
- **Environment Variables**: **لا تضف أي متغيرات بيئة إطلاقاً**.

### الخطوة 4: النشر
اضغط على **"Deploy"**. خلال أقل من دقيقة، سيكون نظام ورشتك متاحاً ويعمل على رابط دائم خاص بك!

> **ملاحظة بخصوص إعادة التحميل (Page Refresh)**: تم تضمين ملف `vercel.json` مع إعداد SPA Rewrite (`/(.*) -> /index.html`) بالإضافة إلى دعم الـ Hash Navigation (`#/suppliers`, `#/inventory`) لضمان عدم حدوث خطأ 404 عند تحديث أي صفحة.

## 🔒 أمان وبيانات النظام (Data Safety & Local Storage)

نظرًا لأن قاعدة البيانات تعيش محلياً داخل المتصفح (IndexedDB):
1. **شاشة النسخ الاحتياطي الدورية**:
   - زر **"حفظ نسخة احتياطية"**: ينشئ ملف JSON كامل بجميع جداول وحسابات الورشة مع التاريخ في اسمه.
   - زر **"استرجاع نسخة"**: يتيح استرجاع بياناتك في أي وقت على أي جهاز آخر.
2. **شريط تنبيه ذكي بعد 7 أيام**:
   - يظهر شريط تحذيري هادئ أعلى الشاشة لتذكير المستخدم بعمل نسخة احتياطية في حال مرور 7 أيام على آخر حفظ.
3. **التخزين الدائم (Storage Persist)**:
   - يطلب النظام تلقائياً من المتصفح تفعيل التخزين الدائم (`navigator.storage.persist()`) لمنع المتصفح من تفريغ المساحة تلقائياً.
4. **تصدير Excel وطباعة رسمية**:
   - جميع التقارير (تفصيل التكاليف، أرباح المبيعات، وأعمار الديون) مزودة بزر **تصدير Excel** حقيقي (`.xlsx` عبر مكتبة SheetJS) مع دعم كامل للاتجاه العربي (RTL) بالإضافة إلى تنسيق طباعة ورق A4 رسمي.

## 👥 نظام الصلاحيات ورمز الدخول (PIN Security)

- **شاشة الإعداد الأولية**: عند فتح النظام لأول مرة على متصفح جديد، تظهر شاشة إعداد باللغة العربية لتعيين اسم الورشة واسم صاحب العمل ورمز الدخول (PIN).
- **أمان التشفير**: يتم تشفير الرمز السري (PIN) باستخدام خوارزمية SHA-256 مع Salt عشوائي فريد عبر واجهة المتصفح الرسمية (`Web Crypto API`).
- **الأدوار المتاحة**:
  - `owner` (صاحب العمل / المعلم): وصول لكافة الشاشات وكشوف الأرباح الحقيقية.
  - `purchasing` (مسؤول المشتريات): الموردين، الخامات، ومتابعة الأرصدة.
  - `storekeeper` (أمين المخزن): الخامات، أذون الاستلام، كروت الأصناف، ومحاضر الجرد.
  - `production` (مدير الإنتاج): شجرة المنتجات، أوامر التصنيع، والتشطيب.
  - `accountant` (المحاسب المالي): الفواتير، المقبوضات، المدفوعات، والخزينة.

## 📊 مقارنة الفروق التشغيلية مقارنة بالإصدار السابق المعتمد على خادم

| الميزة | الإصدار المعتمد على خادم (Node + Postgres) | الإصدار الجديد المستقل (100% Frontend) |
|---|---|---|
| **مكان حفظ البيانات** | خادم مركزي بقاعدة بيانات سحابية | داخل متصفح المستخدم عبر IndexedDB (Dexie) |
| **الاعتماد على الإنترنت** | يتطلب اتصالاً مستمراً بالخادم | يعمل بالكامل **Offline** بدون إنترنت |
| **تكاليف الاستضافة** | اشتراك شهري لخادم وقاعدة بيانات | **مجاني مدى الحياة** على أي خدمة Static Hosting |
| **سرعة الاستجابة** | تعتمد على جودة شبكة الإنترنت (Ping) | **لحظية وفورية (0ms)** لأن العمليات تجري محلياً |
| **المزامنة بين الأجهزة** | مزامنة تلقائية عبر الخادم | تتم بنقل ملف النسخة الاحتياطية (JSON) بين الأجهزة |
| **الخصوصية المالية** | البيانات مخزنة على خادم طرف ثالث | البيانات خاصة بنسبة 100% ولا تغادر حاسوب صاحب الورشة |

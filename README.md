نظام ERP متكامل واحترافي موجه للمؤسسات الصناعية، المصانع، والشركات التجارية. صُمم النظام بالكامل بواجهة عربية تفاعلية حديثة من اليمين إلى اليسار (RTL)، ليدير دورة العمل من سلاسل الإمداد والمشتريات وتتبع الخامات، مروراً بشجرة المنتجات (BOM) وأوامر التصنيع والتشطيب، وحتى فواتير المبيعات المحلية والتصدير، حسابات الخزينة والبنوك المتعددة، وتحليلات التكاليف والأرباح اللحظية.

---

## 🌟 المزايا المعمارية والتقنية (Architecture & Highlights)

1. **معمارية خالية من الخوادم (Zero Backend / Serverless)**:
   - يعمل النظام كلياً داخل متصفح المستخدم عبر تقنية `IndexedDB` ومكتبة `Dexie.js`.
   - لا حاجة لاستئجار خوادم سحابية أو قواعد بيانات شهرية مدفوعة (Zero Infrastructure Cost).

2. **تشغيل أوفلاين فوري (100% Offline-First)**:
   - استجابة فائقة السرعة بزمن استجابة فوري (0ms Latency) لجميع العمليات والحركات المحاسبية دون الحاجة لشبكة الإنترنت.

3. **سرية وأمان بيانات المؤسسة (Enterprise Data Privacy)**:
   - جميع الحسابات، التكاليف، وهوامش الربح، وبيانات العملاء والموردين تُخزن محلياً داخل جهازك دون إرسالها لأي طرف ثالث.

4. **تشفير محلي قوي للمستخدمين (Web Crypto SHA-256)**:
   - نظام حماية للأدوار وصلاحيات الوصول عبر رمز مرور رقمي (PIN) مشفر بواسطة خوارزمية `SHA-256` مع Salt عشوائي فريد لكل مستخدم عبر المتصفح مباشرة.

5. **محرك احتساب تكاليف هندسي ومحاسبي نقي (Pure TypeScript Cost Engine)**:
   - حساب فوري لمتوسط التكلفة المرجح، شجرة المنتجات مع نسبة الهالك الصناعي، أجور العمالة، تكلفة ساعات تشغيل الماكينات، وتكلفة البضاعة المباعة (COGS) بدقة تامة ومختبر بـ Vitest.

6. **تصدير إكسيل وتقارير رسمية (Excel & Print Ready)**:
   - إمكانية تصدير كافة الجداول والتقارير المالية والتحليلية إلى ملفات Microsoft Excel حقيقية (`.xlsx`) عبر مكتبة `SheetJS` مع دعم الاتجاه العربي، وتنسيق مخصص لطباعة الفواتير والتقارير على ورق قياس A4.

## 📦 الوحدات الوظيفية للنظام (Enterprise Modules)

### 1. لوحة المؤشرات التنفيذية (Executive Dashboard)
- رؤية مالية وتشغيلية شاملة تعرض:
  - سيولة الخزينة والبنوك النقدية.
  - إجمالي مديونيات الموردين واجبة السداد.
  - مستحقات وتحصيلات العملاء المطلوبة.
  - صافي أرباح الشهر (مخصصة للمدير التنفيذي).
  - أوامر التشغيل الجارية وتنبيهات نواقص المستودع الفورية.

### 2. إدارة الموردين والمشتريات (Suppliers & Purchasing)
- دليل كامل لبيانات الموردين وشروط السداد والسجل التجاري والضريبي.
- تسجيل فواتير المشتريات النقدية والآجلة مع ضريبة القيمة المضافة.
- كشوف حسابات تفصيلية للموردين وجدول استحقاق المدفوعات.

### 3. إدارة المستودعات وسلاسل الإمداد (Inventory & Supply Chain)
- سجل الخامات ومستلزمات الإنتاج مع تحديد وحدات القياس وأسعار الشراء والحد الأدنى للطلب.
- أذون استلام وفحص البضاعة (Goods Receipt Notes - GRN).
- تتبع حركة الخامات اللحظية (Stock Movements Ledger) وسجلات الجرد الدوري والتسويات.

### 4. شجرة المنتجات والتكاليف المعيارية (BOM & Costing)
- بناء شجرة المنتج متعددة المستويات (Bill of Materials).
- ربط الخامات بمعدلات الاستهلاك ونسب الهالك الصناعي التقديرية.
- احتساب نصيب المنتج من أجور العمالة المباشرة وساعات تشغيل الماكينات.

### 5. أوامر التصنيع والتشطيب (Manufacturing & Operations)
- دورة إنتاج على مرحلتين:
  - **مرحلة التصنيع والتشغيل الأولي (Manufacturing)**: استهلاك الخامات من المخزن تلقائياً وتوليد المنتج نصف المصنع.
  - **مرحلة التشطيب والجودة (Finishing & QC)**: إضافة خامات ومصاريف التشطيب، الفحص واستلام المنتج التام في مستودع المنتجات الجاهزة.
- تتبع تكلفة كل دفعة إنتاجية ومقارنتها بالتكلفة المعيارية.

### 6. المبيعات والفواتير والتصدير (Sales, Invoicing & Export)
- فواتير المبيعات المحلية وفواتير التصدير الدولي.
- دعم العملات المتعددة وسعر الصرف ومصاريف الشحن والجمارك.
- احتساب تكلفة البضاعة المباعة (COGS) وصافي هامش الربح لكل فاتورة وصنف لحظياً.
- فواتير مهيأة للطباعة المباشرة وإرسال كشوف الحسابات للعملاء.

### 7. الخزينة والبنوك والتدفقات النقدية (Multi-Account Treasury & Banking)
- دعم حسابات مالية متعددة (خزينة رئيسية نقدية، حساب جاري CIB، حساب عملات أجنبية QNB).
- سندات القبض والصرف، التحويل الداخلي بين الحسابات.
- سجل قيود وتدفقات نقدية تفصيلي (Cash Ledger) مع الرصيد اللحظي بعد كل عملية.

### 8. التقارير المالية والتحليلية (Financial Reports & Analytics)
- **تقرير تكاليف وأرباح الإنتاج**: مقارنة التكاليف المعيارية بالإنتاج الفعلي.
- **تقرير أرباح المبيعات**: صافي الربح حسب العميل، المنتج، والفاتورة.
- **تحليل أعمار الديون (Aging of Receivables)**: 30 / 60 / 90 / 120+ يوماً لإدارة السيولة والتحصيل.
- **حركة الخزينة والسيولة**: تدفقات الإيرادات والمصروفات التشغيلية.

### 9. الأمان والنسخ الاحتياطي وإدارة البيانات (Backup & Data Security)
- تصدير نسخة احتياطية كاملة لكافة بيانات وجداول النظام بملف JSON منظم بنقرة زر.
- استرجاع واستيراد سريع للبيانات على أي جهاز جديد دون فقدان أي سجل.
- تنبيه ذكي بعد 7 أيام لتذكير المستخدم بأخذ نسخة احتياطية.
- تفعيل خاصية التخزين الدائم بالمتصفح (`navigator.storage.persist()`).

## 👥 مصفوفة الصلاحيات وأدوار النظام (RBAC & User Roles)

| الدور | المسمى الوظيفي | نطاق الصلاحيات |
|---|---|---|
| `owner` | **الرئيس التنفيذي (CEO)** | وصول كامل لكافة الشاشات، كشوف الأرباح الحقيقية، وإعدادات النظام المتقدمة |
| `accountant` | **المدير المالي والمراقب (CFO)** | إدارة الفواتير، التحصيلات، سندات الخزينة والبنوك، وتقارير أعمار الديون |
| `production` | **مدير العمليات والتصنيع** | شجرة المنتجات (BOM)، أوامر التصنيع، مراحل التشطيب، ومراقبة الجودة |
| `storekeeper` | **مدير المستودعات واللوجستيات** | أذون الاستلام (GRN)، كروت الأصناف، تتبع الحركات المخزنية، ومحاضر الجرد |
| `purchasing` | **مدير المشتريات وسلاسل الإمداد** | سجل الموردين، فواتير الشراء، ومتابعة حدود إعادة الطلب وتوريد الخامات |

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19, JavaScript (ESNext), HTML5 Semantic RTL.
- **Styling**: Tailwind CSS v4, Lucide React Icons.
- **Data Layer**: Dexie.js (IndexedDB ORM Wrapper).
- **Exporting & Reporting**: SheetJS (`xlsx`) للتقارير المجدولة والطباعة القياسية.
- **Security**: Web Crypto API (SHA-256 with Unique Salt).
- **Tooling & Testing**: Vite 6, Vitest (Pure Logic & Cost Calculations Unit Testing).

## 🌐 النشر على منصات الاستضافة (Deployment)

النظام مصمم ليعمل كـ **موقع ثابت (Static SPA)** جاهز للنشر المجاني على **Vercel** أو **Netlify** أو **GitHub Pages**:

### النشر بضغطة زر على Vercel:
1. ارفع المشروع على مستودع GitHub الخاص بك.
2. سجّل الدخول إلى [Vercel](https://vercel.com) واختر **"New Project"**.
3. حدد مستودع المشروع (`ERP-system`).
4. سيتعرف Vercel تلقائياً على إعدادات **Vite**:
   - **Framework**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. **متغيرات البيئة (Environment Variables)**: لا يلزم أي متغيرات بيئة إطلاقاً.
6. اضغط **Deploy** وسيعمل تطبيقك فوراً برابط HTTPS دائم.

> تم تضمين ملف `vercel.json` المجهز بتوجيه مسارات SPA (`/(.*) -> /index.html`) لدعم التحديث المباشر للصفحات بدون أخطاء 404.

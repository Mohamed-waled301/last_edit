## 💻 متطلبات التشغيل (System Requirements)

* نظام تشغيل: **Windows 10** أو **Windows 11** (معمارية 64-بت).
* معالج: Intel Core i3 / AMD Ryzen 3 أو أعلى.
* ذاكرة عشوائية (RAM): **4 جيجابايت** كحد أدنى (يوصى بـ 8 جيجابايت).
* مساحة تخزين خالية: **500 ميجابايت**.
* يعمل النظام بدون اتصال بالإنترنت بالكامل (Offline-First).

---

## ⚙️ خطوات التثبيت (Installation Steps)

1. قم بتحميل ملف التثبيت `code-systems-cutting-Setup-1.0.4.exe` من رابط التحميل أعلاه.
2. شغّل ملف التثبيت بصلاحيات المستخدم أو المسؤول.
3. **تنبيه حماية الشاشة (Windows SmartScreen):**
   * عند ظهور نافذة التنبيه الزرقاء من Windows Defender، اضغط على **"More info" (مزيد من المعلومات)**.
   * ثم اضغط على زر **"Run anyway" (تشغيل على أي حال)** لإتمام التثبيت.
4. اتبع تعليمات معالج التثبيت حتى النهاية. سيتم إنشاء اختصار للبرنامج على سطح المكتب باسم **"نظام code systems"**.

---

## 🔑 تفعيل النظام (License Activation)

* عند تشغيل البرنامج لأول مرة، ستظهر شاشة تطلب **كود التفعيل**.
* انسخ **كود الجهاز (Machine Code)** الظاهر على الشاشة.
* أرسل كود الجهاز إلى الدعم الفني للحصول على مفتاح الترخيص المخصص لجهازك.
* الصق مفتاح الترخيص واضغط **"تفعيل النظام"** للبدء فوراً.

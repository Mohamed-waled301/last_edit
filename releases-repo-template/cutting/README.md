# نظام code systems — إصدار مصانع الملابس وقص وتشغيل المراحل (Cutting Edition)

نظام متكامل لتخطيط موارد المؤسسات (ERP) مخصص لمصانع وورش الملابس والنسيج، يعمل محلياً بالكامل دون الحاجة لاتصال بالإنترنت (Offline-First).

## 💻 متطلبات التشغيل (System Requirements)

* **نظام التشغيل:** Windows 10 أو Windows 11 بمعمارية 64-بت (x64).
* **المعالج:** Intel Core i3 / AMD Ryzen 3 أو ما يعادله كحد أدنى.
* **الذاكرة العشوائية (RAM):** 4 جيجابايت كحد أدنى (يوصى بـ 8 جيجابايت لضمان سرعة التقارير).
* **مساحة القرص الصلب:** 500 ميجابايت مساحة خالية.
* **بيئة العمل:** يعمل النظام محلياً بالكامل دون الحاجة لأي خادم سحابي أو اتصال دائم بالإنترنت.

---

## ⚙️ خطوات التثبيت وتنبيه الحماية (Installation & Windows SmartScreen)

1. حمّل ملف التثبيت المعتمد `code-systems-cutting-Setup.exe`.
2. شغّل ملف التثبيت بصلاحيات المستخدم أو المسؤول.
3. **تنبيه حماية الشاشة (Windows Defender SmartScreen):**
   * نظراً لأن ملف التثبيت تم بناؤه وتوزيعه بدون شهادة رقمية تجارية مدفوعة (EV Code Signing)، قد يظهر نظام Windows تنبيهاً يفيد بأن الناشر غير معروف (Unknown Publisher).
   * **للتحقق من سلامة الملف:** قارن بصمة ملف التثبيت الرقمية (SHA-256) بالبصمة المنشورة رسمياً في صفحة الإصدار على GitHub.
   * عند التأكد من سلامة البصمة، اضغط على **"More info" (مزيد من المعلومات)** ثم اضغط على زر **"Run anyway" (تشغيل على أي حال)** لمتابعة التثبيت الآمن.
4. اتبع خطوات معالج التثبيت؛ سيتم إنشاء اختصار رسمي على سطح المكتب باسم **"نظام code systems"**.

---

## 🔑 التفعيل الرقمي دون اتصال (Offline License Activation)

يعمل النظام بآلية ترخيص رقمية مشفرة مرتبطة بالعتاد الفعلي للجهاز (Hardware-Bound Offline License) ولا تتطلب أي اتصال بالإنترنت:

1. عند تشغيل البرنامج لأول مرة، تظهر شاشة التفعيل وبها **كود الجهاز (Machine Code)** المكون من 16 خانة فريدة (مثل: `XXXX-XXXX-XXXX-XXXX`).
2. يمكنك الضغط على **"نسخ كود الجهاز"** أو **"حفظ كود الجهاز في ملف نصي"**.
3. أرسل كود الجهاز إلى مطور النظام المعتمد لإصدار مفتاح الترخيص المشفر المخصص لجهازك فقط.
4. الصق مفتاح الترخيص المستلم واضغط **"تفعيل"** ليتم قفل الترخيص على جهازك وبدء العمل مباشرة.
5. **ضمان أمان البيانات:** تتيح شاشة التفعيل دائماً إمكانية **"تصدير نسخة احتياطية من البيانات"** في أي وقت لضمان عدم حجب المستخدم عن بياناته تحت أي ظرف.

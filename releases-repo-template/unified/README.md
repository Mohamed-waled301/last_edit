# نظام code systems — الإصدارات الرسمية المعتمدة (Official Releases)

نظام متكامل لتخطيط موارد المؤسسات (ERP) يعمل محلياً دون الحاجة لاتصال بالإنترنت، متوفر بإصدارين متخصصين:
1. **إصدار مصانع الملابس وقص المراحل (Cutting Edition):** لإدارة المصانع، أوامر القص، مراحل التشغيل وورش الإنتاج، والمخازن.
2. **الإصدار التجاري والمخزني القياسي (Standard Edition):** لإدارة الشركات التجارية، المخازن المتعددة، المشتريات، المبيعات والحسابات.

## 💻 متطلبات التشغيل (System Requirements)

* نظام تشغيل: **Windows 10** أو **Windows 11** (64-بت).
* ذاكرة عشوائية (RAM): **4 جيجابايت** كحد أدنى (يوصى بـ 8 جيجابايت).
* مساحة تخزين خالية: **500 ميجابايت**.
* يعمل النظام بدون اتصال بالإنترنت بالكامل (Offline-First).

---

## ⚙️ خطوات التثبيت (Installation Steps)

1. اختر الإصدار المناسب لطبيعة نشاطك وحمّل ملف التثبيت `.exe`.
2. شغّل ملف التثبيت المكتبي.
3. **تنبيه حماية الشاشة (Windows SmartScreen):**
   * عند ظهور نافذة التنبيه الزرقاء من Windows Defender، اضغط على **"More info" (مزيد من المعلومات)**.
   * ثم اضغط على زر **"Run anyway" (تشغيل على أي حال)** لمتابعة التثبيت.
4. اتبع تعليمات التثبيت حتى ظهور رسالة الاكتمال واختصار سطح المكتب.

## 🔑 تفعيل النظام (License Activation)

* عند أول تشغيل، انسخ **كود الجهاز (Machine Code)** الظاهر في الشاشة.
* تواصل مع إدارة الدعم الفني لتزويدك برمز الترخيص المرتبط برقم جهازك.
* الصق الرمز واضغط **"تفعيل النظام"**.
